## 投稿1: ローンチ告知

**推奨日時:** 11/15（日）20:30
理由: 週末ライドを終えてStravaを開いた流れで見てもらえる時間帯。土曜より日曜夜のほうが週末分のライドが反映されていて、すぐ試せる人が多い。

**本文:**

```
Stravaのライドデータから、自分が6タイプのどのサイクリストかを診断するアプリを作った

坂の比率、平均距離、速度、頻度あたりを見てキャラが決まる。自分は【自分のキャラ名】だった

ログインして期間を選ぶだけ。リンクはリプに

#ロードバイク #Strava
```

**リプ欄:**

```
VeloAva
https://veloava.vercel.app
3ヶ月 / 6ヶ月 / 1年から期間を選べます。結果はカードにして保存・ポストできます
```

**画像:** オーナー本人のシェアカード（結果ページで保存したPNG）。名前・プロフィール画像の写り込みは投稿前に確認。

**狙い:** 宣伝ではなく「仲間が作ったものを見せてもらった」温度で、ロード乗りに自分の結果を試したいと思わせる。

メモ: 【自分のキャラ名】は実際の結果に置き換える（例: 結果がクライマーなら「アルピニスト・クロスだった。峠の番人らしい。そんなに登ってないけど」のように一言足すと自然）。

## 投稿2: キャラの世界観を見せる

**推奨日時:** 11/18（水）21:30
理由: 平日の反応が集まる21〜23時。週末の告知から3日空けて、見逃した人にもう一度届ける。

**本文:**

```
VeloAvaのキャラ、6タイプそれぞれ口癖がある

峠の番人「坂道は、私の舞台だ」
閃光の追跡者「誰も、私の背中は見たことがない」
鋼鉄の巡航者「私のペースに、合わせてみろ」
大地の開拓者「地平線の向こうに、まだ道がある」
万能の勇者「どこでも戦える。それが私の強さだ」
風まかせの自由人「今日も風になる、それだけでいい」

どれになるかはStravaのデータ次第

#ロードバイク #自転車乗りと繋がりたい
```

**リプ欄:**

```
診断はこちら
https://veloava.vercel.app
結果ページの「Xでポスト」から、キャラ画像つきでポストできます
```

**画像:** 「Xでポスト」用OGP画像のうち、`/c/weekend_female`（フリーダム・サニー）と `/c/climber_male`（アルピニスト・クロス）の2枚。対照的な2キャラで振れ幅を見せる。「Xでポスト」ボタン公開前なら画像なしで出し、リプのボタン案内を外す。

**狙い:** 「自分はどれだろう」と思わせ、セリフの中二感で引用ポストやリプでの「自分は○○だった」を引き出す。

## 投稿3: 3連休とシーズン振り返り

**推奨日時:** 11/22（日）20:00
理由: 3連休（11/21〜23）の中日。ライド後でStravaを開いている人が多く、翌日も休みなので試す余裕がある。最終日の月曜夜は翌朝を気にして反応が落ちやすいので避けた。

**本文:**

```
連休で走ったあと、期間を「1年」にして診断し直してみた

3ヶ月だと【3ヶ月の結果キャラ名】、1年だと【1年の結果キャラ名】。夏の峠と秋のロングで結果が変わるのが面白い

今シーズンの振り返りにどうぞ

#ロードバイク #Strava
```

**リプ欄:**

```
https://veloava.vercel.app
期間は3ヶ月 / 6ヶ月 / 1年から選べます
```

**画像:** オーナー本人の3ヶ月版と1年版のシェアカード2枚を並べる。結果が同じだった場合は本文を「1年で見ても【キャラ名】だった。ブレないらしい」に差し替え、カードは1枚。

**狙い:** 一度試した人にも「期間を変えてもう一回」と思わせ、走り納めに向けたシーズン振り返りの定番として印象づける。

メモ: 結果が変わった理由（「夏の峠と秋のロング」）はオーナー自身の実際のライド内容に合わせて書き換える。
